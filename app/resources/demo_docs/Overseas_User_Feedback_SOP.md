# Overseas User Feedback SOP

## 适用范围

本文档适用于海外 App 用户通过应用商店评论、客服邮件、站内反馈、社媒评论提交的问题处理。重点覆盖订阅、退款、广告体验、闪退、账号登录、隐私权限和功能建议。

## 反馈分级

高优先级反馈包括扣费异常、无法使用已购买权益、隐私投诉、集中闪退、同一版本差评快速上升、社媒传播风险。高优先级反馈需要在 2 小时内完成初步确认，并同步给运营、客服和产品负责人。

中优先级反馈包括功能异常、广告体验投诉、登录失败、支付流程卡顿、翻译不准确。中优先级反馈需要在 1 个工作日内给出处理建议。

低优先级反馈包括一般功能建议、轻微文案问题和单点体验反馈。低优先级反馈进入需求池或知识库沉淀。

## 处理流程

客服或运营人员需要先确认用户所在国家、语言、App 版本、设备系统、问题发生时间和用户诉求。如果反馈涉及订阅或退款，需要补充订单号、支付渠道和购买邮箱。

系统应先调用多语言反馈分类模型识别意图、情绪、优先级和责任团队，再调用 Global Knowledge Hub 查询相关 SOP、FAQ 或政策说明。

## 升级规则

以下情况必须转人工或升级：

- 用户反馈重复扣费、无法恢复会员权益或强烈要求退款。
- 同一国家或同一版本在短时间内出现大量负面反馈。
- 反馈包含隐私、数据删除、未授权扣费、儿童保护等合规风险。
- 用户情绪明显激烈，包含投诉监管机构、公开曝光或法律风险表述。

## 输出要求

处理结果需要包含问题分类、关键证据、建议回复、是否转人工、责任团队和后续跟进时间。对外回复必须使用用户语言，并避免承诺无法保证的处理结果。
